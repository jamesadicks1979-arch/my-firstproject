# Pine Script Project

This repository contains starter templates for Pine Script development on TradingView.

## Files

- `study.pine`: A basic indicator template (Simple Moving Average).
- `strategy.pine`: A basic strategy template (Moving Average Crossover).

## Usage

1. Open [TradingView](https://www.tradingview.com/).
2. Open the **Pine Editor** tab at the bottom.
3. Copy the content of `study.pine` or `strategy.pine`.
4. Paste it into the editor and click **Add to Chart**.
