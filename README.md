# AlphaTrend Cross

TradingView Pine Script indicator/strategy based on **AlphaTrend** with **cross** signals.

## What’s included

- `pine/alphatrend_cross_indicator.pine`: Indicator that plots AlphaTrend and marks cross signals.
- `pine/alphatrend_cross_strategy.pine`: Strategy version for basic backtesting (entries on crosses).

## How to use (TradingView)

1. Open TradingView → **Pine Editor**
2. Copy/paste one of the scripts from `pine/`
3. Click **Add to chart**

## Notes

- This is a lightweight, self-contained implementation intended to be easy to tweak.
- Inputs are exposed for ATR length, multiplier, and RSI/MFI selection.
