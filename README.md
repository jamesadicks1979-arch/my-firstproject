# Football Fuel Pro E-Book Builder

Professional youth football nutrition e-book generator with:

- Parent account creation (demo, browser-local storage)
- Child age input
- Weekly training and match schedule with times
- Color-coded priority highlights:
  - **Training days = blue**
  - **Match days = red**
- Auto-generated meal pages (one page per meal) with:
  - Images
  - Meal timing
  - What to eat/drink
  - Digestion/performance timing explanation
- Saturday match banner (`SATURDAY MATCH DAY`) when applicable
- Social media ad copy + quick share links
- Preview link section and Print/PDF export support
- Dedicated easy-flow page for parents:
  - `morning-kickoff-guide.html` for 8:30-10:30 AM kick-offs
  - why large morning meals can hurt comfort/performance
  - 10 night-before meal options
  - exact morning eat/drink timing

## Run

This is a static web project.

1. Open `index.html` in a browser, or
2. Serve with a simple local server:

```bash
python3 -m http.server 8080
```

Then visit:

`http://localhost:8080`
